# Hint ladder

Shared by `/gym-spotter` and `/gym-bug-hunt`. Climb one rung at a time.

1. **Nudge**: a question that points at where to look ("what does this return when the list is empty?").
2. **Pointer**: name the concept or doc to read (function, doc page, pattern name).
3. **Pseudocode**: the shape of the solution in plain steps, no real syntax.
4. **Code**: a minimal snippet for the stuck part only. Only on the user's explicit request.

Stay on the same rung while the user makes progress; climb one rung when they report being stuck again. State the current rung in each reply ("rung 2:") so the user sees the cost of each ask. At rung 4, give the smallest snippet that unblocks, then hand the keyboard back.
